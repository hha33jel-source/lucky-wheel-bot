# بوت عجلة الحظ 🎡 — دليل التشغيل

## ما الذي يتضمنه المشروع؟
- بوت Telegram يفتح واجهة عجلة حظ ويب (Telegram Mini App).
- جوائز بالنقاط فقط.
- محاولة مجانية كل 24 ساعة.
- لا توجد عمليات شراء أو محاولات مدفوعة؛ محاولة مجانية كل 24 ساعة.
- سجل آخر النتائج وقاعدة بيانات SQLite.
- أمر للمشرف لإضافة نقاط: `/addpoints USER_ID AMOUNT`.
- النقاط افتراضية للترفيه فقط ولا تُشترى ولا تُستبدل بأموال حقيقية.

## متطلبات الاستضافة
- استضافة تدعم Python 3.10 أو أحدث.
- رابط HTTPS عام للموقع.
- تشغيل عملية Python باستمرار.
- تخزين دائم للملف `wheel.sqlite3` أو ضبط `DB_PATH` إلى مجلد دائم.

## الإعداد
1. ارفع جميع ملفات المشروع إلى الاستضافة.
2. ثبّت المكتبات:
   `pip install -r requirements.txt`
3. أضف متغيرات البيئة في لوحة الاستضافة:
   - `BOT_TOKEN`: رمز البوت من BotFather (لا تشاركه مع أحد).
   - `WEBAPP_URL`: رابط HTTPS الذي يخدم هذا المشروع، مثل `https://example.com`.
   - `ADMIN_ID`: رقم حساب تلغرام الخاص بالمشرف.
   - `PORT`: غالبًا تحدده الاستضافة تلقائيًا؛ إن لم تحدده استخدم `8080`.
4. اجعل أمر التشغيل `python bot.py` أو استخدم Procfile إذا كانت الاستضافة تدعمه.
5. افتح البوت وأرسل `/start`، ثم اضغط «افتح عجلة الحظ».

## كيف تعرف رقم Telegram ID الخاص بك؟
استخدم بوتًا موثوقًا يعرض رقم Telegram ID، أو أضف أمرًا مؤقتًا في البوت لعرض `update.effective_user.id`. ضع الرقم في `ADMIN_ID` من لوحة الاستضافة.

## ملاحظات مهمة
- لا تضع BOT_TOKEN داخل ملفات عامة أو ترسله في المحادثات.
- يجب فتح الواجهة من زر البوت داخل Telegram؛ التحقق يعتمد على `initData` الموقّع من Telegram.
- رابط `WEBAPP_URL` يجب أن يكون HTTPS، وأن يشير إلى نفس التطبيق.
- تأكد من أن الاستضافة تسمح بتشغيل البوت والموقع معًا، وأنها لا توقف العمليات الخاملة.
- البيانات مخزنة محليًا في SQLite. استخدم مجلدًا دائمًا أو نسخًا احتياطيًا حتى لا تضيع البيانات عند إعادة النشر.
- النقاط افتراضية داخل البوت وليست أموالًا حقيقية.
- هذه نسخة أولية قابلة للتشغيل؛ قبل الاستخدام الواسع أضف حدود طلبات ومراقبة وأتمتة نسخ احتياطيًا.
